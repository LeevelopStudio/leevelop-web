# Leevelop Web

Official website for **Leevelop** — strategy, product design and software engineering.

This repository contains the production implementation of the Leevelop corporate website. The visual direction is based on the Leevelop Framer prototype while the production code is maintained independently with semantic, reusable React components.

## Stack

- Next.js
- React
- TypeScript
- App Router
- CSS
- Vercel

## Getting started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npm run build
```

## Project structure

```text
app/          Next.js routes, layout and global styles
components/   Reusable UI, layout and landing-page sections
public/       Static brand assets, images and icons
```

## Delivery

Development is organized through small feature branches and reviewable pull requests. The first milestone is **v0.1 — Framer → Production**.
